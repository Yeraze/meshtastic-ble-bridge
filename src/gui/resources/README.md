# GUI Resources

## Icons

Icons are generated programmatically by the tray application.

For custom icons, add:
- `icon.ico` - Windows application icon (for PyInstaller)
- `icon_connected.png` - Connected state icon (optional)
- `icon_disconnected.png` - Disconnected state icon (optional)

## Icon Requirements

- Format: ICO for Windows executable, PNG for runtime
- Size: 64x64 pixels recommended
- Colors: Green for connected, Gray for disconnected
